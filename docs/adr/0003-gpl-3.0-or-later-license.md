# 0003 — License under GPL-3.0-or-later

- Status: accepted
- Date: 2026-07-20

## Context

egon-core is a derivative work of egon.io, which is licensed under
GPL-3.0. Distributing a derivative requires a GPL-compatible license; we do
not have the option of relicensing code we did not author.

## Decision

The package is licensed `GPL-3.0-or-later` (see `LICENSE`, `package.json`).

## Consequences

- Legally sound with respect to the upstream project.
- Copyleft applies to consumers: applications that embed egon-core and are
  distributed must themselves be GPL-compatible. This limits adoption in
  proprietary products — a known and accepted trade-off, not an oversight.
- Any code merged into egon-core must be GPL-3.0-compatible.
